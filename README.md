# Camp Base de l’Everest · novembre 2026

Resum del trekking de 13 dies de Lukla al Camp Base de l’Everest i tornada, amb mapa i tracks GPX per descarregar.

## Web per descarregar

El botó «Tota la web» baixa `ebc-2026-web.zip` de la release `web`. L’Action `release` el regenera a cada push a `main`.

## PDFs

`pdf/` es genera amb `python3 tools/pdf/gen.py` (cal Python 3 i Google Chrome): mapes OSM amb els GPX i disseny «Expedició 1953». Llegeix les dades d'`index.html`, els tracks de `gpx/` i els horaris de `tools/pdf/times.json`.
